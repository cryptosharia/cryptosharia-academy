Kenapa sidebar lebih cocok?

Karena halaman ini bukan halaman baca, tapi halaman kerja.

Accordion cocok kalau kontennya sedikit. Tapi editor landing page punya banyak field. Kalau pakai accordion terus, nanti user akan mengalami:

Terlalu banyak scroll.
Harus buka-tutup section berkali-kali.
Susah tahu posisi sekarang.
Susah lompat dari Hero ke Harga.
Sulit membandingkan antar section.
Area desktop kanan-kiri terbuang.

Dengan sidebar, admin terasa seperti CMS sungguhan.

Ukuran yang ideal

Untuk layar desktop:

admin-layout {
  max-width: 1280px;
  margin: 0 auto;
  display: grid;
  grid-template-columns: 280px 1fr;
  gap: 24px;
}

Kalau mau ada panel kanan:

grid-template-columns: 260px minmax(0, 1fr) 280px;

Tapi untuk tahap sekarang, aku sarankan jangan 3 kolom dulu. Pakai 2 kolom sudah cukup kuat dan lebih mudah diimplementasikan.

Apakah accordion harus dihapus total?

Menurutku: untuk desktop, iya, sebaiknya tidak lagi bergantung pada accordion utama.

Tapi di dalam setiap section, kamu masih boleh pakai accordion kecil.

Contoh di menu Hero:

Hero / Banner Utama

[Konten Teks]
[Gambar / Visual]
[CTA Button]
[Pengaturan Tampilan]

Jadi accordion tetap ada, tapi hanya untuk sub-bagian kecil, bukan untuk seluruh halaman.

Kekurangan kalau pakai sidebar

Biar objektif, ada beberapa konsekuensi:

Implementasi lebih kompleks.
Perlu state activeSection.
Form harus dirender berdasarkan section yang dipilih.
Perlu desain responsive tambahan.
Kalau user ingin melihat semua field sekaligus, sidebar membuatnya tidak langsung terlihat.

Tapi untuk admin profesional, kekurangan itu masih sangat layak.

Rekomendasi paling praktis untuk implementasi

Jangan langsung rombak semua. Lakukan bertahap.

Tahap 1

Buat layout 2 kolom:

Kiri: sidebar menu section
Kanan: tetap tampilkan accordion/form section terpilih
Tahap 2

Hapus accordion utama di konten landing page.

Tahap 3

Setiap menu sidebar menampilkan form spesifik.

Tahap 4

Tambahkan preview kecil atau status panel.

Keputusan desain yang aku sarankan

Gunakan ini:

Desktop:
Sidebar kiri sticky + form editor kanan

Mobile:
Dropdown pilih section + form section

Jangan gunakan:

Semua section dalam accordion panjang

Karena desain sekarang memang sudah rapi, tapi masih terasa seperti admin sederhana. Dengan sidebar, naik kelas jadi seperti mini CMS / professional landing page builder.
